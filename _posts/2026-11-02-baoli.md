## 一、题目信息
- 平台：Pikachu
- 分类：暴力破解 -> 基于表单的暴力破解
- 难度：简单
- 通关标识：页面回显 `login success`

## 二、考点
1. 基于表单的登录认证机制漏洞
2. 缺乏防暴力破解的安全机制（无验证码、无次数限制、无 Token）
3. Burp Suite 抓包与 Intruder 模块的使用
4. Cluster bomb（集束炸弹）攻击载荷组合爆破

## 三、题目内容
页面提供了一个基础的登录表单，包含 Username 和 Password 输入框。后端未设置任何登录失败次数限制、验证码防护或 Token 校验。目标是利用自动化工具和字典，猜解出正确的用户名与密码组合。

## 四、解题步骤

**1. 抓取登录请求**
启动 Burp Suite 拦截功能，在页面随意输入账号密码（如 `admin` / `123`），点击 Login。Burp 成功捕获到 POST 请求，请求体内容如下：

```http
POST /vul/burteforce/bf_form.php HTTP/1.1
Host: 127.0.0.1
Content-Type: application/x-www-form-urlencoded
Content-Length: 23

username=admin&password=123
```

**2. 发送至 Intruder 模块**
右键点击抓到的请求，选择 `Send to Intruder`（快捷键 `Ctrl + I`）。

**3. 设置攻击载荷位置**
在 **Positions** 标签页，点击右侧的 `Clear §` 清除默认标记。然后分别选中 `admin` 和 `123`，点击 `Add §` 将其包裹，设置为变量。此时请求体变成：
`username=§admin§&password=§123§`

**4. 配置字典与攻击模式**
- 在 **Payloads** 标签页，将 **Attack type** 设置为 `Cluster bomb`（集束炸弹）。
- **Payload set 1**（对应 username）：加载常见的用户名字典（如包含 `admin`）。
- **Payload set 2**（对应 password）：加载常见的弱口令字典（如包含 `123456`、`admin` 等）。

**5. 开始爆破并分析结果**
点击 `Start attack` 开始爆破。观察返回的数据包：
- 失败请求的响应长度（Length）通常是一致的（提示密码错误）。
- 找到其中一条 **Length 明显不同** 的请求。查看其 Response 内容，可以看到页面返回了成功提示，并且找到了正确的凭证组合（例如 `admin` / `123456`）。

**6. 验证登录**
将爆破出的正确账号密码填入网页表单，点击 Login，页面成功返回：

```text
login success
```
爆破完成，成功通关。

## 五、知识点解析
1. **暴力破解原理**：在缺乏有效防护机制（如验证码、锁定机制）的情况下，攻击者可通过自动化脚本和字典，穷举所有可能的组合来猜测正确的凭证。
2. **Burp Intruder 的几种攻击类型**：
   - `Sniper`（狙击手）：单参数依次爆破。
   - `Battering ram`（破城锤）：多参数使用同一个字典。
   - `Pitchfork`（草叉）：多参数一对一匹配。
   - `Cluster bomb`（集束炸弹）：多参数全排列组合，适合本题账号密码都不确定的情况。
3. **结果判定技巧**：在爆破结果中，不能仅看状态码（通常都是 200），需要通过比较响应包的 `Length`（长度）或响应内容的关键字来寻找差异。

## 六、总结与防御
本题是暴力破解最基础的入门关卡，核心在于熟练掌握 Burp Suite 抓包、设置变量、配置 `Cluster bomb` 攻击模式以及通过响应长度判断结果。

**安全防御建议**：
- 强制使用强密码策略，避免弱口令。
- 在登录接口增加图形验证码或短信验证码。
- 对同一账号或 IP 的登录失败次数进行限制（如失败 5 次锁定 15 分钟）。
- 引入 CSRF Token 机制防止请求重放。
