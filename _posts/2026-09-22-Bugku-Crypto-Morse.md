# Bugku Crypto .!?
## 题目信息
平台：Bugku CTF Crypto
题目描述：详见附件
考察：**摩尔斯电码解密**（解释：摩尔斯电码使用点`.`和短横`-`组合代表字母数字，本题用`.` `!` `?`替代传统摩尔斯符号，需要做字符替换再解密）

## 解题思路
下载附件得到密文，题目符号只有`.` `!` `?`。将`!`替换为`-`，`?`替换为空格，还原成标准摩尔斯电码，再在线解密摩尔斯电码得到flag。

## 操作步骤
1. 下载附件，打开查看密文。
2. 字符替换：`.`保持不变，`!` → `-`，`?` → 空格。
```python
# 替换脚本
cipher = "......-..!-.-..?..-.-.-?--..-..?.-..-..?.-..-..?--..-..?.-.-.-"
res = cipher.replace('!','-').replace('?',' ')
print(res)
```
3. 将替换后的标准摩尔斯电码复制到摩尔斯解密网站解密。
4. 解密得到flag：`flag{Morsec0de_1s_fun}`
```text
flag{Morsec0de_1s_fun}
```
5. 将flag填入输入框提交，题目完成。
```text
提交成功
```

## 知识点&名词解释
1. **摩尔斯电码(Morse Code)**：早期电报编码，用点、划和间隔组合表示字符。CTF题目经常替换符号进行变形。
2. **字符替换**：Crypto常见变形手段，把`.` `-`换成其他符号，需要先映射还原再解密。
3. **Crypto密码学**：CTF题型，考察各类加密、编码算法的识别与解密。

## 总结
这是一道简单的密码学入门题，核心考点是识别变形摩尔斯电码。先观察密文只有三类符号，推测是摩尔斯的替换，把符号还原后即可解密拿到flag。
