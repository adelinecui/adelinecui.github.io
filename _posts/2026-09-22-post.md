# Bugku Web POST
## 题目信息
平台：Bugku CTF Web
题目描述：post，需要发送POST请求获取flag
考察：**POST请求**（解释：HTTP的一种提交数据的请求方式，数据放在请求体内，不会在浏览器地址栏显示，区别于GET把参数放在URL后面）

## 解题思路
本题不能直接在浏览器地址栏访问，浏览器普通刷新是GET请求。需要构造POST请求，提交参数`what=flag`，服务器返回flag。
手机浏览器无法发送POST请求，需要电脑，可使用curl命令、Python requests库、Burp Suite抓包工具完成。

## 操作步骤
1. 启动场景拿到目标网页地址。
2. 方法1：curl命令（终端执行）
`curl -d "what=flag" 目标地址`
> -d：curl参数，用于携带POST提交的数据
3. 方法2：Python requests库
```python
import requests
res = requests.post(url="目标链接", data={"what":"flag"})
print(res.text)
