# Bugku Web source
## 题目信息
平台：Bugku CTF Web
题目描述：我哥说渗透我只用linux环境
考察：**git源码泄露**（解释：网站服务器没有保护好……
## 解题思路
网站存在.git目录泄露，直接浏览器访问看不到有用内容。使用git‑dumper工具把整个git仓库下载到本地，查看git历史提交记录，回滚历史版本找到被删除/隐藏的flag.txt。

## 操作步骤
1. 启动场景，访问网页，发现页面没有直接给出flag。
2. 使用git‑dumper工具，下载目标地址的.git仓库到本地。
`git‑dumper 目标网址/.git ./git_dump`
3. 进入下载好的git_dump文件夹。
4. 使用`git reflog`查看所有历史提交记录（reflog：git命令，查看全部操作日志，可以看到被删除的提交）。
5. 使用`git cat‑file ‑p 对象id`读取历史文件flag.txt内容。
6. 获取flag，提交平台。

## 遇到的坑
1. 直接浏览器访问/.git只会列出文件夹，不能直接读取文件，必须下载完整git仓库；
2. 当前版本没有flag，flag保存在历史提交记录，不能只看现在网页；
3. git reflog有时候看不到HEAD记录，需要使用工具读取对象。

## 知识点总结
1. git版本管理工具，会保存每一次文件修改；
2. .git目录泄露高危漏洞，泄露后源代码、敏感文件全部被获取；
3. git‑dumper专门工具，完整下载网站泄露的git仓库；
4. git reflog可以找回被删除、回滚丢弃的提交版本。
